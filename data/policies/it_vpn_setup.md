# IT Access & VPN Setup Guide

## VPN Setup
1. Download the company VPN client (GlobalProtect) from the IT portal.
2. Log in using your company email and the temporary password sent by IT during onboarding.
3. Select the "Corporate-Primary" gateway from the dropdown.
4. On first login, you will be prompted to set up multi-factor authentication (MFA) using
   the Okta Verify app.
5. Once connected, you should see a green "Connected" status in the VPN client.

## Common VPN Issues
- If the VPN fails to connect, check that your local internet connection is stable and
  try switching from Wi-Fi to a wired connection.
- If MFA codes are not being accepted, ensure your phone's clock is set to automatic
  network time, as Okta Verify codes are time-sensitive.
- Persistent connection failures should be reported to the IT helpdesk with a screenshot
  of the error code.

## Laptop and Software Requests
New software installation requests must be raised via the IT ticketing system and are
typically approved within 1 business day for pre-approved software, or 3-5 business days
for new/unlisted software requiring security review.

## Password Policy
Company passwords must be at least 12 characters, include one uppercase letter, one
number, and one special character, and must be changed every 90 days. Passwords cannot
be reused from the last 5 password changes.
